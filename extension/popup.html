Mendcraft

This extension stays on this computer.

It lets Mendcraft copy text or a link from another Chrome tab, put it on the studio canvas, switch tabs by name, and paste into a field after you pinch to confirm.

  • It never reads password or payment fields.
  • It never submits a form for you.
  • Site access is only so copy and paste can work in the tab you asked for.
  • The tabs permission is so it can find a tab by name and open a page that refuses to load in Mendcraft's built-in panel.
  • Storage holds the last copied item on this device only.

Open Mendcraft Studio and look for “Chrome extension connected”.
